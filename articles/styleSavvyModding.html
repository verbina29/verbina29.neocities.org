prerequisites

  1. Legally obtain a backup copy of the game. For legal reasons, I do not endorse pirating video games, but I'm sure we all know what that really means.
  2. Configure the emulator of your choice. I'm using Azahar, but other Citra forks should be basically the same.
  3. Set up the game in said emulator.
  4. If on Linux (or like a Mac I guess but that's worse), configure Wine or Bottles or something so that you can run Windows programs.
  5. CriPakTools/CriPakGUI
  6. rELPKckr
  7. Kuriimu. Kuriimu 1, not Kuriimu2. I couldn't get Kuriimu2 to work, so no idea if it's better or not.
  8. CpkPatcher
  9. A hex editor. I've been using ImHex but I don't know shit no idea if this one's any good it has dark mode and seemed to have the most features when i was looking for one.
  10. Know how to open a terminal.
  11. (Optional, but highly recommended.) ugrep

OKAY HERE'S THE REAL INSTRUCTIONS

  1. Dump the game's RomFS. In Azahar, this is simply right clicking on the game in the game list and clicking "Dump RomFS", and it automatically opens up the dumped RomFS for you. If you're modding the English version of the game, you likely want the EN folder, but for other languages you'll want the appropriate folder.
  2. You will notice that all of the files are .cpk. Extract these using CriPakGUI.
    1. Open CriPakGUI.
    2. File ==> Open CPK
    3. Navigate to wherever you put your CPK files or the RomFS dump and open the CPK you want to extract.
    4. Click "Extract Files"
    5. Navigate to wherever you want the extracted files and open that location.
    6. Wait patiently.
  3. Open whatever folder you extracted them to.
  4. Figure out what type of file these really are, using your hex editor. ELPK files will conveniently start with ELPK in ASCII, while MSBT files will conveniently start with MsgStdBn in ASCII. Convenient!
    • If it's an ELPK, extract it via rELPKckr, using the command wine rELPKckr.exe file, replacing "file" with the filename of the ELPK file. If you're on windows just like, remove the wine part, figure it out yourself i'm too sexy to use windows in 2025.
    • The extracted ELPK should contain MSBT files, so you can proceed to the next step.
  5. To more easily find the files you want to edit, you can run the command ugrep --encoding=UTF-16LE -r "search" --exclude=*.bak, replacing "search" (keeping it in the quotes) with a term from the file you want to edit. Or suffer manually looking through 5k text files, I'm not going to tell you how to live. The --exclude=*.bak part excludes the .bak files that Kuriimu creates so that you won't get the unedited versions if you're replacing a specific word or something.
  6. Because Kuriimu only can edit files with specifically the .msbt extension, you'll need to rename the .msgs files to .msbt.
  7. Edit the .msbt files using Kuriimu.
    1. Navigate to your .msbt files and open them.
    2. Look, it's a text editor, I'm sure you can figure it out on your own.
    3. There is no god that can help you if you want to edit the formatting.
    4. Click the save icon in the top bar to save after you're done editing the text.
  8. Rename the .msbt files back to whatever they were before.
  9. If applicable, repack the ELPK file using rELPKckr. This is just wine rELPKckr.exe folder, replacing "folder" with the name of the folder rELPKckr unpacked the ELPK to.
  10. Patch the CPK file using CpkPatcher.
    1. Put your edited MSBT or ELPK in a folder with structure mirroring that of the CPK file. So if the CPK file has directories like whatever.cpk/msbt/fileIwantToEdit, you'd need a directory like patch/msbt/fileIwantToEdit, with the "patch" directory containing only the files you want to edit and the folders that those are contained in.
    2. Run wine CpkPatcher.exe sourceCPK patchDir outputCPK, replacing "sourceCPK" with the original, unedited CPK file, "patchDir" with the directory mirroring the CPK file's structure, and outputCPK with the filename and path to output to.
  11. Right click the game, then press Mods Location under the Open menu.
  12. Create a folder called romfs, and put your patched CPKs in it, mirroring the directory structure of the RomFS dump. For Style Savvy: Fashion Forward's US version's English language, this would be romfs/USA/EN.
  13. Launch the game and hope it works.
